# Sticker Star

Ciao! Ho un serverino su cui gira Proxmox e ho creato una VM con debian sulla quale vorrei far girare, tutto sotto web, un "programma" per aiutare mia figlia a fare la brava. Il programma di base dei bollini. Ne avevo già creato uno ma non mi piace https://bollini.lukinetto.it. Deve avere una dashboard dove mia figlia può vedere quanti punti ha accumulato e cosa può fare per accumularli e come spenderli, dietro invece ci deve essere una pagina admin dove posso inserirli. Fammi il progetto e dimmi passo passo come devo pare per mandarlo online sul mio server
